# FCS Prompt Invocations

Each prompt file is fully self-contained. Read the one file and complete the task — no other files needed.

---

## Write a blog article

```
Read BLOG_WRITING_PROMPT.md fully, then write a blog article for this keyword: [YOUR KEYWORD]
```

## Blog article follow-up (run after the first draft)

```
Read BLOG_WRITING_PROMPT_FOLLOWUP.md and apply every check to the article above.
```
