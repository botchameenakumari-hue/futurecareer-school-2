# Keyword authority analysis (October 2026)

Three reports built from both keyword Google Sheets (35 tabs), the Search Console export inside the first sheet, and the site source.

| File | Purpose |
|---|---|
| `01-report-authority-in-existing-topics.md` | Gaps and fixes inside the topics the site already targets (career options, degrees, courses, services, salary long tail). Prioritised build list. |
| `02-report-authority-in-uncovered-topics.md` | Topics few publishers cover, chosen by evidence beyond tool volume: 17 themes with page ideas, guardrails and a SERP spot-check log. |
| `03-report-low-volume-authority-in-covered-topics.md` | Low and zero-volume keywords inside topics the site already covers: every keyword classified, heading-level coverage of all pages, 28 angle families, Search Console wording gaps, pages ranked by long-tail load. |
| `appendix/A1-site-page-inventory.csv` | Every page on the site with its keyword pattern type. |
| `appendix/A2-search-console-queries-mapped.csv` | The 1,000 Search Console queries with topic group and nearest page. |
| `appendix/A3-report1-matched-keywords.csv` | Every sheet keyword behind each Report 1 item. |
| `appendix/A4-report2-matched-keywords.csv` | Every sheet keyword behind each Report 2 theme. |
| `appendix/A5-sheet-tab-summary.csv` | Fit verdict per sheet tab. |
| `appendix/A6-noise-and-anomaly-log.csv` | Exclusion rules, one-month spikes, decaying keywords. |
| `appendix/A7-is-x-good-career-candidates.csv` | Next "is X a good career" candidates. |

Volumes, KD and CPC are the sheets' tool figures and were not re-verified. Page coverage was checked against this repository, not the live site.
| `appendix/A8-all-keywords-classified.csv` | All 100,387 unique keywords: cluster, fit, noise flag, heading status, nearest page, modifiers (17 MB). |
| `appendix/A9-longtail-angle-groups-covered-topics.csv` | 2,789 angle groups with host page and suggested handling. |
| `appendix/A10-cluster-summary.csv` | Coverage audit per topic cluster. |
| `appendix/A11-existing-pages-ranked-by-unanswered-longtail.csv` | 234 existing pages ranked by the long tail they could absorb. |
| `appendix/A12-search-console-unanswered-queries.csv` | Search Console queries no heading answers. |
| `appendix/A13-angle-families.csv` | 28 angle families with counts and examples. |
